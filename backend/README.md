# Простые заметки

Учебный backend на Django и Django REST Framework. Это упрощённый первый этап,
а не полная реализация большого ТЗ из корневого README.

Есть пространства (папки) и заметки с заголовком и текстом. Их можно создавать,
просматривать, изменять и удалять. Заметку можно перенести в другое пространство.
При удалении пространства заметки сохраняются без папки.

Пока нет пользователей и токенов: все заметки общие для тех, кто имеет доступ
к серверу. Приватность добавим вместе с авторизацией. База — SQLite, отдельный
сервер базы и Docker не нужны.

## Запуск в PowerShell

Открой терминал в папке `backend` и выполни:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python manage.py migrate
.\.venv\Scripts\python manage.py runserver
```

Открой http://127.0.0.1:8000/api/ — там ссылки на заметки и пространства.
Django REST Framework показывает данные и формы для запросов в браузере.
Запуск предназначен для своего компьютера.

## Что попробовать

1. Открой `/api/spaces` и создай пространство с именем «Учёба».
2. Открой `/api/notes` и создай заметку, выбрав это пространство.
3. Открой `/api/notes/1` (подставь полученный id), измени текст.
4. Запроси `/api/notes?space=1`, чтобы увидеть заметки одной папки.
5. Удали пространство. Заметка останется, её `space` станет `null`.

Пример тела запроса `POST /api/notes`:

```json
{
  "title": "Подготовка к паре",
  "content": "Разобрать модели Django",
  "space": 1
}
```

Чтобы создать заметку без папки, не передавай `space` или укажи `null`.

| Метод | Адрес | Действие |
|---|---|---|
| GET, POST | `/api/spaces` | Список пространств, создание |
| GET, PUT, PATCH, DELETE | `/api/spaces/1` | Просмотр, изменение, удаление пространства |
| GET, POST | `/api/notes` | Список заметок, создание |
| GET, PUT, PATCH, DELETE | `/api/notes/1` | Просмотр, изменение, удаление заметки |

`PUT` обновляет объект целиком, `PATCH` — только переданные поля.
Адреса записаны без завершающего `/`. Списки возвращаются обычными JSON-массивами.

## Как устроен код

- `apps/notes/models.py` — две таблицы: пространство и заметка.
- `apps/notes/serializers.py` — проверка данных и преобразование в JSON.
- `apps/notes/views.py` — действия с заметками и пространствами.
- `urls.py` — адреса API. Router создаёт маршруты для ViewSet.
- `settings.py` — подключение приложений и SQLite.
- `manage.py` — запуск команд Django.
- `apps/notes/migrations/` — описание создания таблиц, сгенерированное Django.
- `__init__.py` — пустые файлы, обозначающие Python-пакеты.

`ModelViewSet` даёт стандартные операции с таблицей, поэтому нам не нужно
вручную писать пять почти одинаковых обработчиков. В `NoteViewSet` добавлен
только выбор заметок по пространству.

Начни разбор с `models.py`, затем переходи к сериализаторам, обработчикам и URL.
