### Unit (11)

- Пароль хранится только как хеш, email нормализуется, строковое представление пользователя — его email.
- Пользователя нельзя создать без email.
- `create_superuser` выставляет флаги `is_staff` и `is_superuser`.
- `RegisterSerializer` создаёт пользователя и отклоняет пароль короче 8 символов.
- У новой заметки пустой текст, нет закрепа и пространства.
- Заметка может лежать в пространстве и иметь несколько тегов.
- При удалении пространства заметка сохраняется, её `space` становится `null`.
- `DefaultPagination`: 20 элементов на страницу, параметр `page_size`, максимум 100.
- `IsOwner` пускает владельца заметки и владельца заметки, к которой относится вложение.

### Бизнес-логика (7)

| Тест | Требование |
|------|-----------|
| Имена пространств и тегов уникальны в рамках одного пользователя, у другого пользователя такие же имена допустимы | FR-03, FR-04 |
| Запрос чужой заметки возвращает `404` | NFR-02 |
| Нельзя привязать к своей заметке чужое пространство или тег — `400` | NFR-02 |
| Закреплённая заметка первая даже при сортировке `created_at` | FR-07 |
| Поиск находит заметку по части слова («замет») и по словоформе («заметки») | FR-05 |
| Фильтр по пространству и тегу одновременно возвращает только нужную заметку | FR-06 |
| При удалении заметки файл вложения удаляется с диска | FR-08 |

### Integration (2)

- **Авторизация:** регистрация → вход → обновление токена → выход → повторное обновление тем же `refresh` получает `401`. Это прямая проверка критерия FR-01 «после выхода токен больше не работает».
- **Работа с заметками:** регистрация и вход → создание пространства и тега → создание заметки с ними → закреп → загрузка вложения → поиск → удаление.

### Smoke (2)

- `/api/schema/` и `/api/docs/` отвечают `200`.
- `/api/notes` без токена отвечает `401`.

## Запуск проекта и проверок

Для Windows добавлен скрипт `start.ps1` в корне репозитория. Он создаёт виртуальное окружение и ставит зависимости, если их ещё нет, применяет миграции и запускает бэкенд и фронтенд в двух окнах PowerShell. После запуска:

- фронтенд — http://localhost:5173/
- Swagger — http://127.0.0.1:8000/api/docs/

Запуск проверок:

```bash
# бэкенд
cd backend
pytest
flake8 .
ruff check .

# фронтенд
cd frontend
npm run test:unit    # Vitest
npm run test:smoke   # Playwright
npm run lint         # oxlint
```
